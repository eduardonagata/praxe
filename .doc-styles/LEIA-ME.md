# Estilos de referência (.docx)

Cada arquivo `.docx` nesta pasta é um **documento de referência do Pandoc**: a extensão
usa os estilos dele (fontes, margens, cabeçalhos, numeração) como moldura ao converter
um markdown em `.docx`.

## Como adicionar um novo estilo

1. Copie um `.docx` existente desta pasta (ou gere um novo com o comando
   *Markdown → DOCX: Gerar estilo padrão*).
2. Abra o arquivo no Word ou LibreOffice e edite os **estilos** — "Título 1", "Título 2",
   "Corpo de texto", cabeçalho e rodapé. O conteúdo de exemplo é irrelevante: apenas a
   definição dos estilos é aproveitada.
3. Salve com um nome descritivo, por exemplo `parecer-juridico.docx`.

O novo estilo aparece automaticamente na lista de renderização — nenhuma configuração
adicional é necessária.
